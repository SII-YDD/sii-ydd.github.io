# Di Yang — Visual direction

- User preference: colorful, fashionable, distinctive; no green and no journal-style layout.
- Palette: electric blue `#3158f5`, coral `#fb653e`, soft lavender `#ded9f6`, cool background `#f7f8fc`, ink `#19202e`.
- Typography: self-hosted Space Grotesk for display and UI; system sans-serif for readable prose.
- Layout: large personal wordmark, asymmetrical hero, animated toroidal token sculpture, one featured research card followed by two supporting studies.
- Spacing: 4 / 8 / 12 / 16 / 24 / 32 / 48 / 78 px. Desktop content max-width 1208 px within a 1320 px shell.
- Accessibility: semantic sections, visible focus, skip link, native citation dialog and details, reduced-motion support, explicit animation pause, mobile layouts and print styles.
- Template reuse: Scholar Pages bibliography and citation engine; bespoke visual design.
